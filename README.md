# Jogo da Matemática

App de console em C# (.NET 9) para treino matemático (The C# Academy). Conta com as 4 operações, modo aleatório, validação algorítmica para divisões exatas e histórico de partidas.

## Funcionalidades
- **Operações Base:** Soma, Subtração, Multiplicação e Divisão (5 rodadas por jogo).
- **Modo Aleatório:** Sorteia as operações matemáticas.
- **Validação de Divisão:** Algoritmo que impede divisão por zero e resultados decimais.
- **Histórico:** Registro de partidas salvo em memória durante a execução.

## Como Executar
Requer o SDK do .NET 9 instalado.

Abra o terminal na pasta do projeto e execute:
`dotnet run`
